# Pokemon sprites

The numbered PNG files in this directory are the HeartGold/SoulSilver sprites
from the [PokeAPI sprites repository](https://github.com/PokeAPI/sprites),
pinned at commit `9c09bbcfaf87eb77eea528cdbe3e9157ad6f2276`.

Pokemon and Pokemon character names are trademarks of Nintendo. The project
uses these sprites for this non-commercial battle-planning interface.
