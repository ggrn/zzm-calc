# Parser and constraint-run fixtures

Synthetic HGSS-shaped native DeSmuME files generated by `scripts/generate-fixtures.mjs`. The default first-Champion rules ban Pokéwalker encounters and importing species from another game; trade evolution of a locally obtained Pokémon is allowed. The legal Ghost pool is therefore Gengar and Misdreavus. Champion samples stay at the floor-average baseline level 48 and use IV 0, 15, and 31 tiers alongside nature and EV assumptions. Use the UI average +1..+5 buttons for level projection. These files target this parser and are not complete emulator gameplay saves.
